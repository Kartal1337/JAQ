# X (Twitter) Şablonu

**Karakter limiti:** 280 (tek tweet) veya thread
**Ton:** Direkt, keskin, tartışma açan

## Tek Tweet Yapısı

```
[Güçlü önerme veya soru — max 240 karakter, hashtag için yer bırak]

#hashtag1 #hashtag2
```

## Thread Yapısı (daha iyi etkileşim)

```
Tweet 1: [Hook — en cesur iddia veya soru] 🧵

Tweet 2: [Bağlam — neden önemli]

Tweet 3: [Nokta 1]

Tweet 4: [Nokta 2]

Tweet 5: [Nokta 3]

Tweet 6: [Sonuç + CTA — RT iste veya soru sor]
```

## Hook Formülleri

- "Hot take: [tartışmalı görüş]"
- "[Rakam] yıldır [X] yapıyorum. Öğrendiğim tek şey:"
- "Kimse konuşmuyor ama [insight]"
- "[X] öldü mü? Hayır. Ama [Y] değişti."

## Notlar

- Thread ise 1. tweet standalone olmalı (RT edildiğinde anlam taşımalı)
- Hashtag max 2 — fazlası spam gibi görünür
- Sade dil, karmaşık cümlelerden kaçın
